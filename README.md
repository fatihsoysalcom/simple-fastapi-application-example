# Simple FastAPI Application Example

This example provides a basic FastAPI application with a few endpoints. It serves as the foundational Python code that would be deployed using Gunicorn and Nginx, as described in the accompanying article. It demonstrates simple GET requests, path parameters, and optional query parameters.

## Language

`python`

## How to Run

1. Install FastAPI and Uvicorn: `pip install fastapi uvicorn`
2. Run the application: `python main.py`
3. Access in your browser: `http://localhost:8000/` or `http://localhost:8000/hello/World`
